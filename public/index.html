Email Notifications
Postmark and SES use HTTPS APIs — bypass cloud SMTP restrictions and scale cheaply.
Find this under Servers → [your server] → API Tokens.
Default: outbound. Postmark also supports broadcast but transactional should always use outbound.
Postmark Setup
1. Sign up at postmarkapp.com and wait for account approval (usually under an hour during business hours)
2. Verify your sending domain in Sender Signatures → Add Domain. Postmark gives you DKIM and Return-Path DNS records — add both in Netlify.
3. Open your default Server → API Tokens → copy the Server token and paste above
4. Set the Sender Email to an address on your verified domain (e.g. noreply@field-mark.app)
AWS SES Setup
1. In AWS Console: SES → Identities → verify your sender email
2. In IAM → Users → create a user with the AmazonSESFullAccess policy
3. Create an Access key for that user and paste both values above
4. While in sandbox mode, you can only send to verified addresses. Request production access in SES for unlimited sending.
